# Dwellio AI Rules

- Always use reusable components
- Maintain Dwellio design consistency
- Follow typography system strictly
- Use spacious layouts
- Preserve calm visual rhythm
- Avoid dense interfaces

- Avoid inconsistent spacing
- Avoid excessive borders
- Use premium restraint

- Use TypeScript
- Use reusable components

- Avoid hardcoded values

- Keep transitions subtle

- Avoid flashy interactions
