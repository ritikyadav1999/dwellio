# Dwellio Fundamentals

## Brand Philosophy

Dwellio is not a rental marketplace.

Dwellio is a premium urban living and relocation experience focused on:
- trust
- calmness
- hospitality
- seamless living transitions
- emotional reassurance

The experience should feel:
- luxurious
- warm
- architectural
- spacious
- premium
- human-centered

---

# Design Language

## Keywords
- Calm luxury minimalism
- Editorial architecture aesthetic
- Premium hospitality
- Warm urban living
- Cinematic softness
- Restrained elegance

Avoid:
- SaaS dashboards
- Startup gradients
- Futuristic UI
- Marketplace clutter
- Operational density

---

# Typography

## Serif Font
Cormorant Garamond

Usage:
- Hero headings
- Section titles
- Editorial emphasis

## Sans Font
Inter

Usage:
- Body text
- UI labels
- Metadata
- Inputs
- Navigation

---

# Color System

## Primary Background
Warm off-white

## Secondary Background
Soft beige / muted stone

## Primary Text
Soft charcoal

## Accent
Muted black

## Borders
Low-opacity neutral gray

Avoid:
- Bright saturated colors
- Neon accents
- Cold blues

---

# Spacing System

Use spacious layouts.

Principles:
- generous whitespace
- calm visual rhythm
- breathing room
- large section spacing

Avoid:
- crowded sections
- dense cards
- tight layouts

---

# Border Radius

Soft rounded corners.

Never overly rounded.

Use:
- elegant restraint
- architectural smoothness

---

# Shadows

Soft subtle depth only.

Avoid:
- heavy shadows
- floating SaaS cards
- aggressive elevation

---

# Interaction Principles

Motion should feel:
- cinematic
- restrained
- tactile
- premium

Avoid:
- flashy animations
- bouncy motion
- exaggerated movement
