# Dwellio Motion System

## Motion Philosophy

Motion should feel:
- calm
- restrained
- cinematic
- luxurious

Avoid:
- flashy transitions
- bouncy animations
- aggressive movement

---

# Hover Motion

Duration:
200ms–300ms

Style:
- soft scale
- subtle depth
- smooth easing

---

# Page Transitions

Use:
- fade transitions
- soft reveals
- smooth scrolling

Avoid:
- hard cuts
- dramatic transitions

---

# Card Interactions

Cards may:
- slightly elevate
- softly zoom imagery
- increase shadow subtly

Motion should remain minimal.

---

# Button Interactions

Buttons should feel:
- tactile
- premium
- responsive

Avoid:
- exaggerated hover effects

---

# Scroll Motion

Use:
- subtle fade-in
- minimal upward movement

Motion should support:
- calm storytelling
- premium pacing
