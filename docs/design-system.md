# Dwellio Design System

## Brand Philosophy

Dwellio is a premium urban living and relocation experience focused on:
- trust
- calmness
- hospitality
- emotional reassurance
- seamless living transitions

The product should feel:
- premium
- warm
- architectural
- spacious
- calm
- trustworthy

Avoid:
- marketplace clutter
- SaaS dashboard aesthetics
- startup-style gradients
- operational density
- futuristic UI noise

---

# UX Philosophy

## Hospitality Over Marketplace

Dwellio should feel like:
- a concierge experience
- a guided living service
- a premium relocation experience

NOT:
- a transactional listing platform
- a crowded marketplace

---

## Emotional Calmness

Interfaces should reduce:
- cognitive load
- stress
- friction
- operational fatigue

Users should feel:
- reassured
- guided
- emotionally safe
- organized

Avoid:
- dense layouts
- overwhelming choices
- aggressive CTAs
- noisy interfaces

---

# Visual Language

## Keywords

- Calm luxury minimalism

- Restrained elegance

---

## Layout Philosophy

Use:
- spacious layouts
- generous whitespace
- restrained hierarchy
- calm visual rhythm
- large section spacing

Avoid:
- clutter
- crowded cards
- dense UI
- excessive borders

---

# Typography Philosophy

## Serif
Playfair Display / Cormorant Garamond

Use for:
- hero sections
- editorial headings
- premium emphasis

## Sans
Inter

Use for:
- body content
- navigation
- UI labels
- forms

Maintain:
- generous line-height
- restrained typography hierarchy
- spacious rhythm

---

# Motion Language

Motion should feel:
- calm
- restrained
- cinematic
- tactile
- premium

Use:
- soft fades
- subtle depth transitions
- gentle hover motion

Avoid:
- flashy animations
- bouncy movement
- exaggerated transitions

---

# Component Philosophy

- maintain visual calmness
